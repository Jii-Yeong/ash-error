# ASH//ERROR 게임 소개 및 플레이 가이드

## 1. 게임 개요

`ASH//ERROR`는 Phaser 기반의 2D 액션 슈팅 플랫폼 게임입니다. 플레이어는 한 화면 안에서 이동·점프·대시하며 적을 처치하고, 잠긴 전투 방을 클리어한 뒤 포탈을 통해 다음 방으로 이동합니다. 각 스테이지의 마지막 방에는 보스전이 배치됩니다.

게임의 핵심 경험은 다음과 같습니다.

- 전투: 원거리 적, 근접 적, 비행 적과의 혼합 전투
- 이동: 플랫폼 점프, 구덩이 회피, 대시, 마지막 스테이지의 비행 이동
- 성장: 전투 중 획득하는 네 종류의 무기와 무기별 발사감·투사체 차이
- 진행: 스테이지별 배경·지형·음악·보스 패턴의 변화
- 분위기: 픽셀 아트 캐릭터와 어두운 SF 인터페이스, 효과음과 BGM을 결합한 연출

현재 코드에는 다음 5개 스테이지가 정의되어 있습니다.

| 순서 | 이름            | 이동 방식 | 특징                                     |
| ---- | --------------- | --------- | ---------------------------------------- |
| 1    | THE CITY        | 지상      | 기본 조작과 전투를 익히는 시작 구간      |
| 2    | THE BACK ALLEYS | 지상      | 발판·구덩이·네온 분위기와 강화된 적 배치 |
| 3    | THE UNDERGROUND | 지상      | 방패·포획·천장 위협과 siege 이벤트       |
| 4    | HELL            | 지상      | 돌진·낙하·방사 패턴과 전용 보스전        |
| 5    | THE RETURN      | 비행      | 공중 편대, 최종 보스와 엔딩              |

각 스테이지는 일반 전투 방과 보스 방으로 구성됩니다. 스테이지 3은 방패·포획·천장 위협, 스테이지 4는 돌진·낙하·방사 패턴, 스테이지 5는 비행 편대와 최종 보스전을 중심으로 전투 흐름을 구성합니다.

## 2. 플레이 방법

1. 타이틀 화면에서 `ENTER`를 눌러 게임을 시작합니다.
2. 캐릭터를 이동시키며 적을 조준하고 마우스로 공격합니다.
3. 전투 중 떨어진 무기는 가까이에서 `E`로 획득해 4칸 인벤토리에 담고, 숫자키로 슬롯을 바꿔 씁니다.
4. 방 안의 모든 적을 처치하면 방이 해제됩니다.
5. 클리어 포탈 근처에서 `W` 또는 `↑`를 눌러 다음 방으로 진입합니다.
6. 일반 방을 통과하고 보스를 처치해 다음 스테이지로 진행합니다.
7. 사망하면 `R` 또는 `ENTER`를 눌러 현재 게임을 다시 시작합니다.

`ESC` 또는 화면 우상단의 일시정지 버튼으로 전투를 멈추거나 다시 진행할 수 있습니다.

### 조작법

| 입력                           | 기능                    |
| ------------------------------ | ----------------------- |
| `A` / `D`, `←` / `→`           | 좌우 이동               |
| `W`, `↑`, `SPACE`              | 점프                    |
| `S`, `↓`                       | 빠르게 낙하             |
| `SHIFT`                        | 대시                    |
| 마우스 이동                    | 조준                    |
| 마우스 버튼                    | 사격                    |
| `E` (무기 근처)                | 무기 획득·장착          |
| 숫자키 `1`~`4`                 | 무기 슬롯 전환          |
| `W` / `↑` (클리어 포탈 앞)     | 다음 방 진입            |
| `R` / `ENTER` (사망·엔딩 화면) | 재시작 또는 다시 플레이 |
| `ESC` / 일시정지 버튼(우상단)  | 일시정지·재개           |

기본 무기는 `SMG`이며, 게임에는 `SHOTGUN`, `BURST RIFLE`, `RAIL RIFLE`을 포함한 4종 무기가 있습니다. 무기마다 발사 속도, 탄 수, 산탄도, 관통력, 반동과 피격 피드백이 다릅니다. 전투 중 떨어진 무기를 `E`로 4칸 인벤토리에 담고 숫자키로 즉시 바꿔 쓸 수 있어, 상황에 맞는 무기를 골라 대응합니다.

## 3. 실행 방법

### 요구 환경

- Node.js `22.x`
- pnpm `10.34.5`

### 설치 및 개발 서버 실행

```bash
pnpm install
pnpm dev
```

개발 서버는 Vite로 실행되며, 클라이언트 작업 디렉터리는 `client`입니다. 브라우저에서 터미널에 표시된 로컬 주소를 엽니다.

### 빌드 및 검증

```bash
pnpm build
pnpm lint
pnpm test
pnpm test:e2e
```

배포 시 Vercel의 Root Directory는 `client`, Framework Preset은 `Vite`, Node.js 버전은 `22.x`로 설정합니다.
