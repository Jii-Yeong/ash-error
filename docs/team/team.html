팀 구성

Soot 팀은 서지영과 이혜원으로 구성된 2인 개발팀입니다. 서지영은 게임의 핵심 플레이 시스템과 전투 콘텐츠, 비주얼 적용을 중심으로 구현했고, 이혜원은 오디오 제작·기술 파이프라인과 레벨 디자인, 무기 연출을 중심으로 완성도를 높였습니다.

TEAM MEMBER 01

서지영

게임플레이 시스템, 적·보스 전투, 스테이지 진행과 컷신, 스프라이트·UI 적용, 게임플레이 회귀 검증을 담당했습니다.

TEAM MEMBER 02

이혜원

오디오 시스템과 에셋 제작, 레벨·클리어 흐름 설계, 무기·팔 리그, 설정 UI와 CI 기반 품질 검증을 담당했습니다.

서지영

게임플레이 시스템 · 전투 콘텐츠 · 비주얼 구현

핵심 게임 시스템

  • Phaser 기반 게임의 초기 구조와 플레이어 이동, 점프, 대시, 피격, 사망·재시작 흐름 구현
  • 방 잠금, 적 생성과 처치 집계, 클리어, 포탈 진입, 다중 방·다중 스테이지 진행 구조 설계
  • 씬에 집중된 책임을 적 생성, 방 진행, 전투, 스테이지 전환, 에셋 로딩 등의 전용 시스템으로 분리
  • 관리자 이동과 무적 모드, HUD 상태 연동, 콜드 로드와 와이드 화면 대응

플레이어·무기·전투

  • 플레이어의 지상·공중 이동과 스테이지별 모습, 사망·착지 애니메이션 연결
  • 총기 4종의 피해, 연사, 산탄, 관통, 반동, 투사체 풀과 무기 획득·드롭·인벤토리 규칙 구현
  • 근접형·원거리형·비행형 적의 추적, 공격, 지형 충돌, 구덩이 추락, 사망 연출 구현
  • 피격 플래시, 공격 예고, 접근 범위, 탄막 명암과 같은 전투 피드백 조정

적·보스 콘텐츠

  • 스테이지 1~5의 일반 적 구성과 스테이지별 전용 적 패턴 구현
  • 1스테이지 레이저, 2스테이지 감시·에너지포, 3스테이지 흡입·내려찍기, 4스테이지 다단계 지옥 보스, 5스테이지 공중 탄막 보스 구현
  • 보스 페이즈 전환, 무적 구간, 체력 UI, 공격 예고와 사운드 이벤트 연결
  • 무기별 지속 피해와 보스 상태 시간을 계산해 핵심 패턴 노출 횟수와 목표 전투 시간을 회귀 테스트로 고정

스테이지 연출과 비주얼 적용

  • 스크롤 맵, 패럴랙스 배경, 지형·바닥·발판 스킨과 스테이지별 에셋 선행 로딩 구현
  • 플레이어·일반 적·보스 아틀라스와 애니메이션 상태를 게임 로직에 연결
  • 3스테이지 강하와 포위, 4스테이지 화면 파괴, 5스테이지 귀환과 회복 엔딩 연출 구현
  • 포탈, 타이틀, HUD, 조작 가이드와 SpriteCook 공격 효과의 크기·레이어·좌표 보정

안정화와 검증

  • 전투·스테이지·에셋 로딩 회귀 테스트와 Playwright E2E 시나리오 유지
  • 배경 선행 로딩, 투사체 풀, 지연 로드로 초기 로딩과 런타임 성능 개선
  • 실제 플레이에서 발견된 충돌, 사망 연출, 방 조기 클리어, 카메라·화면비 문제 수정

이혜원

오디오 엔지니어링 · 레벨 디자인 · 전투 연출

오디오 시스템과 런타임

  • 게임 이벤트와 오디오 재생을 분리한 AudioDirector 및 오디오 이벤트 계약 설계
  • 부팅 에셋과 지연 로딩 에셋을 분리하고 현재·다음 스테이지 음악만 준비하는 로딩 전략 구현
  • BGM 루프, 페이드, 볼륨, 재생 상태와 화면 전환 타이밍 연결
  • Ogg/Opus 포맷 통일과 지연 로드 실패 시 폴백 등 배포 환경 안정화

BGM·SFX 제작과 오디오 QA

  • 스테이지 정서에 맞춘 생성형 BGM 프롬프트 설계, 후보 생성, 청취와 최종 선별
  • 루프 구간 편집, 포맷 변환, 라우드니스·주파수·이음매 측정과 후보 비교 도구 제작
  • CC0 효과음 선별과 라이선스 기록, 총기·피격·보스 패턴 효과음 자체 합성
  • 프롬프트 버전, 테이크 번호, 측정 결과와 채택 근거 문서화

레벨 디자인과 전투 동선

  • 플레이어 점프·대시 거리와 적 추적 범위를 기준으로 스테이지 1~5의 방 배치 재구성
  • 발판, 벽, 구덩이, 엄폐와 적 배치를 이용해 학습 구간과 조합 전투의 순서 설계
  • 3·4스테이지의 구덩이와 발판 역할, 방패 적 약점과 추락 처리를 공간 설계에 맞춰 보정
  • 일반 전투방의 ROOM CLEARED 피드백과 보스 전환 연출을 구분
  • 5스테이지 마지막 편대와 포탈 사이에 900px 이상의 보스전 정비 구간 확보

무기 비주얼과 플레이어 팔 리그

  • 무기 스프라이트 4종의 도트 확정과 총기별 탄알·총구·반동 표현 제작
  • 몸에서 팔을 분리하고 조준 방향, 좌우 반전, 플레이어 프레임에 맞춰 결합하는 리그 구현
  • 앞팔·뒷팔 앵커, 총구 위치, 버스트·산탄 발사점과 무기 교체 시 반동 상태 보정
  • 무기 외형과 손 위치를 실제 게임 화면에서 픽셀 단위로 조정

개발 기반과 품질 보조

  • 타입 검사, lint, 단위 테스트, E2E, 빌드를 묶은 CI 검증 워크플로 구축
  • E2E 단일 워커·재시도 설정과 레벨 배치 픽스처 유지
  • 사운드·그래픽 설정 화면과 화면비별 UI 정렬 구현
  • 병행 개발된 보스 패턴과 레벨 디자인 변경을 통합하고 전투 디렉터와 클리어 UI 회귀 정리

역할 경계와 협업 방식

두 사람의 역할은 기능 단위로 나누되, 실제 플레이 경험으로 이어지는 지점은 함께 검증했습니다.

영역 주 담당 협업 방식
핵심 게임플레이·전투 로직 서지영 이혜원이 플레이·리뷰 중 발견한 판정과 흐름 문제를 재현하고 함께 보정
적·보스 패턴과 스테이지 연출 서지영 이혜원이 레벨 동선과 오디오 큐 관점에서 연결
레벨 디자인·전투 공간 이혜원 서지영이 적 행동, 지형 충돌, 스테이지 시스템으로 구현
BGM·SFX와 오디오 파이프라인 이혜원 서지영이 보스 상태와 게임 이벤트에 재생 신호를 연결하고 플레이로 확인
무기 서지영: 획득·인벤토리·피해·투사체 이혜원: 스프라이트·팔 리그·총구·반동 연출
UI·접근성 서지영: HUD와 게임 상태 연동 이혜원: 설정 화면, 화면비 정렬, 방 클리어 피드백과 사용성 보정
테스트·QA 서지영: 게임플레이 회귀와 E2E 시나리오 이혜원: CI, 오디오 측정, 레벨 도달성 검증과 교차 리뷰

이혜원이 설계한 전투 공간과 소리는 서지영이 구현한 전투 상태와 이벤트를 통해 동작하고, 서지영이 만든 적·보스 패턴은 이혜원의 레벨 배치와 오디오 피드백을 거쳐 플레이 경험으로 완성됩니다. 최종 결과는 코드 리뷰, 자동 테스트와 두 사람의 실제 플레이를 함께 사용해 확인했습니다.
