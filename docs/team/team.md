# 팀 소개 및 담당 영역

Soot 팀은 서지영과 이혜원으로 구성된 2인 개발팀입니다. 서지영은 게임의 핵심 플레이 시스템과 전투 콘텐츠, 비주얼 적용을 중심으로 구현했고, 이혜원은 오디오 제작·기술 파이프라인과 레벨 디자인, 무기 연출을 중심으로 완성도를 높였습니다.

이 문서는 현재 원격 메인 브랜치의 최신 커밋 `c487372`까지 총 405개 커밋을 확인해 작성했습니다. 작성자명이 다르게 기록된 커밋은 실명 기준으로 합쳤으며, 병합 커밋과 다른 브랜치 변경을 통합한 커밋은 협업 흐름 확인에만 사용하고 역할은 실제 변경 파일과 기능 커밋을 기준으로 분류했습니다. 커밋 수는 기여율을 뜻하지 않습니다.

## 팀 구성

| 이름   | 핵심 역할                                 | 주요 담당 영역                                                                                     |
| ------ | ----------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 서지영 | 게임플레이 시스템·전투 콘텐츠·비주얼 구현 | 플레이어, 무기 로직, 적과 보스, 스테이지 진행, 컷신과 엔딩, 스프라이트·UI 적용, 게임플레이 테스트  |
| 이혜원 | 오디오 엔지니어링·레벨 디자인·전투 연출   | BGM·SFX, 오디오 런타임과 제작 도구, 전투방·클리어 흐름 설계, 무기·팔 리그, 설정 UI, CI와 품질 검증 |

## 서지영

### 핵심 게임 시스템

- Phaser 기반 게임의 초기 구조와 플레이어 이동, 점프, 대시, 피격, 사망·재시작 흐름 구현
- 방 잠금, 적 생성과 처치 집계, 클리어, 포탈 진입, 다중 방·다중 스테이지 진행 구조 설계
- 씬에 집중된 책임을 적 생성, 방 진행, 전투, 스테이지 전환, 에셋 로딩 등의 전용 시스템으로 분리
- 관리자 이동과 무적 모드, HUD 상태 연동, 콜드 로드와 와이드 화면 대응

대표 근거는 초기 전투 흐름을 만든 `09bd5c5`, 방 전투 구조를 분리한 `538f436`, 클리어 포탈 전환을 적용한 `62b5b86`, 게임 씬 책임을 다시 나눈 `94fa65f`입니다.

### 플레이어·무기·전투

- 플레이어의 지상·공중 이동과 스테이지별 모습, 사망·착지 애니메이션 연결
- 총기 4종의 피해, 연사, 산탄, 관통, 반동, 투사체 풀과 무기 획득·드롭·인벤토리 규칙 구현
- 근접형·원거리형·비행형 적의 추적, 공격, 지형 충돌, 구덩이 추락, 사망 연출 구현
- 피격 플래시, 공격 예고, 접근 범위, 탄막 명암과 같은 전투 피드백 조정

무기 드롭과 스테이지 3 공성 이벤트를 만든 `f296f00`, 총기별 고유 효과를 추가한 `14dc6b3`, 4칸 인벤토리를 적용한 `a48e43c`, 투사체 수명과 적 수명을 분리한 `2e40f2a`·`5e199c6`이 이 영역을 보여 줍니다.

### 적·보스 콘텐츠

- 스테이지 1~5의 일반 적 구성과 스테이지별 전용 적 패턴 구현
- 1스테이지 레이저, 2스테이지 감시·에너지포, 3스테이지 흡입·내려찍기, 4스테이지 다단계 지옥 보스, 5스테이지 공중 탄막 보스 구현
- 보스 페이즈 전환, 무적 구간, 체력 UI, 공격 예고와 사운드 이벤트 연결
- 무기별 지속 피해와 보스 상태 시간을 계산해 핵심 패턴 노출 횟수와 목표 전투 시간을 회귀 테스트로 고정
- 스테이지 3의 매복·포획·봉쇄형 적과 스테이지 4·5의 돌진·탄막형 적을 실제 플레이 피드백에 맞춰 반복 보정

`d608181`, `4f4e280`, `3abec86`, `c0d2db3`, `0caa9c5`는 각 스테이지 보스의 핵심 패턴을 도입한 커밋이며, `97cff8d`에서 공통 보스 전투 책임을 분리했습니다. 이후 `0f0ec67`, `db91f5b`, `1170b38`, `9bd60ad`, `3d93ef8`에서 스테이지별 패턴 노출 목표를 수치화하고, `f8f5e3c`에서 보스별 레일건 장갑 계산을 공용화했습니다.

### 스테이지 연출과 비주얼 적용

- 스크롤 맵, 패럴랙스 배경, 지형·바닥·발판 스킨과 스테이지별 에셋 선행 로딩 구현
- 플레이어·일반 적·보스 아틀라스와 애니메이션 상태를 실제 게임 로직에 연결
- 3스테이지 강하와 포위, 4스테이지 화면 파괴, 5스테이지 귀환과 회복 엔딩 연출 구현
- 포탈, 타이틀, HUD, 조작 가이드와 SpriteCook 공격 효과 등 픽셀 아트 에셋의 크기·레이어·좌표 보정

`4949324`의 패럴랙스 배경, `4817abf`의 강하 컷신, `e1a9688`의 화면 파괴 컷신, `e3cf42e`의 최종 엔딩이 대표 사례입니다. 캐릭터와 보스 스프라이트 적용은 `6c5b74a`, `8b99a7d`, `15c994a`, `d78f0b0` 등으로 이어지며, `ce59597`과 `a60f9af`에서는 5스테이지 조준 표식과 탄막 예고를 전용 스프라이트로 교체했습니다.

### 안정화와 검증

- 전투·스테이지·에셋 로딩 회귀 테스트와 Playwright E2E 시나리오 유지
- 배경 선행 로딩, 투사체 풀, 지연 로드로 초기 로딩과 런타임 성능 개선
- 실제 플레이에서 발견된 충돌, 사망 연출, 방 조기 클리어, 카메라·화면비 문제 수정

`c00cf6f`의 배경 로딩 최적화, `ac86446`의 투사체 풀, `067a974`의 공중 적 사망 완료 대기, `f0ef5e6`의 4스테이지 종료 순서 검증이 대표적입니다. `c6b651a`와 `8be29b1`에서는 강하·화면 파괴 전환 중에도 직전 무기와 양팔 자세가 유지되도록 렌더 순서를 보정하고 테스트를 추가했습니다.

## 이혜원

### 오디오 시스템과 런타임

- 게임 이벤트와 오디오 재생을 분리한 `AudioDirector` 및 오디오 이벤트 계약 설계
- 부팅 에셋과 지연 로딩 에셋을 분리하고 현재·다음 스테이지 음악만 준비하는 로딩 전략 구현
- BGM 루프, 페이드, 볼륨, 재생 상태와 화면 전환 타이밍 연결
- Ogg/Opus 포맷 통일과 지연 로드 실패 시 폴백 등 실제 배포 환경 안정화

`949d0dd`와 `184c08a`에서 오디오 기반 구조를 만들었고, `17ceb36`·`eca257a`에서 초기 로딩을 줄였습니다. `01c01c2`에서는 지연 로드가 불가능한 환경에서도 효과음이 유지되도록 보강했습니다.

### BGM·SFX 제작과 오디오 QA

- 스테이지 정서에 맞춘 생성형 BGM 프롬프트 설계, 후보 생성, 청취와 최종 선별
- 루프 구간 편집, 포맷 변환, 라우드니스·주파수·이음매 측정과 후보 비교 도구 제작
- CC0 효과음 선별과 라이선스 기록, 총기·피격·보스 패턴 효과음 자체 합성
- 프롬프트 버전, 테이크 번호, 측정 결과와 채택 근거를 `docs/audio-assets.md`에 기록

음원 점검 도구를 만든 `1ee73f1`, 사운드 명세를 정리한 `b7d1029`, SMG 발사음을 합성한 `850e2ea`, 3·5스테이지 BGM을 확정한 `2f9b5b4`, 후반 보스 패턴음을 제작한 `eed35c3`이 대표 사례입니다.

### 레벨 디자인과 전투 동선

- 플레이어 점프·대시 거리와 적 추적 범위를 기준으로 스테이지 1~5의 방 배치 재구성
- 발판, 벽, 구덩이, 엄폐와 적 배치를 이용해 학습 구간과 조합 전투의 순서 설계
- 지상전에서 비행전으로 이어지는 후반 스테이지 분량과 순찰 범위, 진입 위치 보정
- 3·4스테이지의 구덩이와 발판 역할을 분리하고, 방패 적의 약점과 추락 처리를 공간 설계에 맞춰 보정
- 일반 전투방의 `ROOM CLEARED` 피드백과 보스 전환 연출이 충돌하지 않도록 클리어 흐름 구분
- 5스테이지 마지막 편대와 포탈 사이에 900px 이상의 정비 구간을 두어 보스전 준비 시간 확보
- 도달 가능성 테스트, 적 수 검증, 실제 플레이 후속 목록으로 레벨 변경 검증

`a5b9d5c`에서 초반 학습 순서를 다듬고, `4864e83`에서 전투 지형 규칙을 세웠으며, `f7a7a05`와 `1af6ce7`에서 전 스테이지 배치와 엄폐 공간을 재구성했습니다. 설계 근거는 `0384efd`와 `6bb4d58`에 문서화했습니다. 이후 `90ea5d8`에서 3~5스테이지의 신규 적 학습 순서와 후반 전투 동선을 다시 정리했고, `7f526c2`에서 5스테이지 보스 전 정비 구간을 수치와 테스트로 고정했습니다.

### 무기 비주얼과 플레이어 팔 리그

- 무기 스프라이트 4종의 도트 확정, 총기별 탄알·총구·반동 표현 제작
- 몸에서 팔을 분리하고 조준 방향, 좌우 반전, 플레이어 프레임에 맞춰 결합하는 리그 구현
- 앞팔·뒷팔 앵커, 총구 위치, 버스트·산탄 발사점과 무기 교체 시 반동 상태 보정
- 무기 외형과 손 위치를 실제 게임 화면에서 픽셀 단위로 조정

`7884751`, `c28c692`, `d291d5e`에서 무기 외형과 게임 연결을 완성했고, `5b20b46`, `7685e34`, `e4589ee`에서 양팔 리그를 구축했습니다. `4e1ba37`과 `a1cd097`은 리그와 실제 발사 판정을 함께 맞춘 수정입니다.

### 개발 기반과 품질 보조

- 타입 검사, lint, 단위 테스트, E2E, 빌드를 묶은 CI 검증 워크플로 구축
- E2E 단일 워커·재시도 설정과 레벨 배치 픽스처 유지
- 사운드·그래픽 설정 화면과 화면비별 UI 정렬 구현
- 코드 리뷰에서 발견된 게임플레이·엔딩·오디오 문제 재현과 후속 수정
- 병행 개발된 보스 패턴과 레벨 디자인 변경을 통합하고 클리어 UI 회귀를 정리

`22a9a00`과 `bb05bc9`가 CI 기반을 만들었고, `3abe008`·`a859be5`가 설정 UI를 추가했습니다. `f0ce7d1`은 리뷰 결과를 실제 코드 수정으로 연결한 사례입니다. 최신 메인의 `7ce4bf1`에서는 보스 패턴 브랜치를 레벨 디자인 변경과 통합하면서 전투 디렉터와 테스트를 맞췄고, `de03dd7`에서는 보스방의 고유 처치 연출을 해치던 중복 클리어 알림을 제거했습니다.

| 영역                             | 주 담당                                | 협업 방식                                                             |
| -------------------------------- | -------------------------------------- | --------------------------------------------------------------------- |
| 핵심 게임플레이·전투 로직        | 서지영                                 | 이혜원이 플레이·리뷰 중 발견한 판정과 흐름 문제를 재현하고 함께 보정  |
| 적·보스 패턴과 스테이지 연출     | 서지영                                 | 이혜원이 레벨 동선과 오디오 큐 관점에서 연결                          |
