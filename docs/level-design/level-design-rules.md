# 레벨 디자인 공통 규칙

모든 스테이지의 지형, 적 배치, 전투 흐름에 적용하는 전역 기준이다. 스테이지별 예외는 해당 스테이지 데이터와 주석에 이유를 남긴다.

## 지형과 투사체

| 요소 | 이동 규칙 | 투사체 규칙 | 레벨에서의 역할 |
| --- | --- | --- | --- |
| 발판 (`platform`) | 아래에서는 통과하고 위에 착지하는 일방통행 지형 | 플레이어·적의 일반 탄 모두 차단 | 높이, 이동 경로, 사선 차단, 엄폐 |
| 벽 (`wall`) | 모든 면이 막힌 지형 | 플레이어·적의 일반 탄 모두 차단 | 넘거나 대시해야 하는 전면 장애물 |
| 구덩이 (`pit`) | 바닥이 끊기며 추락하면 피해 | 해당 없음 | 의도적인 이동 과제 |

- 발판은 캐릭터 이동에는 일방통행이지만, 탄환에는 단단한 구조물이다.
- 비행 적을 발판 위에 둘 때는 플레이어가 그 발판에 올라가거나 옆 사선에서 공격할 수 있어야 한다. 발판 아래에 적을 가둬 공격 불가능한 배치를 만들지 않는다.
- 원거리 적과 발판을 함께 둘 때는 발판 위·아래 중 어느 높이가 유리한지 읽을 수 있어야 한다. 단순히 탄을 피하기 위한 천장으로 쓰지 않는다.
- 숨 고르기용 엄폐 발판은 너비 180~240px, 바닥 대비 높이 100~116px를 기준으로 한다. 플레이어와 적의 탄을 모두 막으므로, 가장자리로 나와야 반격할 수 있는 짧은 전투 비트로 사용한다.
- 엄폐 발판 아래에는 지상 적을 두지 않고, 같은 화면 안의 단독 비행·원거리 적을 통해 위·아래 위치 전환을 유도한다. 여러 엄폐 발판을 이어 긴 안전 천장으로 만들지 않는다.
- 벽은 발판보다 강한 이동 제약을 만드는 도구다. 엄폐가 필요하다는 이유만으로 벽을 두지 말고, 반드시 넘어야 하는 선택을 의도한 곳에만 쓴다.
- 스테이지 5는 비행 이동이므로 발판·벽·구덩이를 쓰지 않고, 화면 경계만 지형으로 쓴다.

## 탄환과 적

- 플레이어 탄환은 카메라 화면 밖으로 나가면 즉시 사라진다. 보이지 않는 적에게 미리 피해를 줄 수 없다.
- 적이 카메라 화면에 보이지 않는 상태에서는 플레이어 탄환 충돌도 피해로 처리하지 않는다.
- 기본 무기 탄환은 적 한 기를 맞히면 사라진다. 관통 수는 무기 설정으로만 예외를 둔다.
- 적 탄환은 플레이어가 보이는 화면 안에서 피해를 주므로, 자체 수명과 지형 충돌 규칙을 따른다.

## 이동 기준

| 항목 | 값 |
| --- | ---: |
| 이동 속도 | 300 px/s |
| 점프 속도 | 560 px/s |
| 최대 점프 높이 | 약 130.7 px |
| 같은 높이 최대 점프 거리 | 280 px |
| 대시 거리 | 약 129.2 px |
| 안전 점프 간격 | 196 px 이하 |
| 한계 점프 간격 | 266 px 이하 |

- 필수 경로의 발판 이동은 기본적으로 안전 점프 간격 안에 둔다.
- 한계 점프는 선택 경로 또는 보상이 있을 때만 쓴다.
- 발판 하나만 갈 수 있어서는 안 된다. 다음 발판이나 바닥으로 안전하게 이어지는지 확인한다.

## 구덩이와 전투

- 스테이지 1에는 구덩이를 두지 않는다.
- 첫 구덩이는 적과 겹치지 않는 단독 구간에서 보여 준다.
- 이후에만 사격, 추적, 이동 동선과 겹치는 구덩이를 쓴다.
- 지상 적을 구덩이 위나 지형 내부에 생성하지 않는다.

## 적 배치와 진행

- 새 적 유형은 다른 위협과 겹치지 않게 먼저 만나게 한다.
- 적 유형을 한 번 읽은 뒤에 조합 전투를 둔다.
- 생성 좌표만으로 거리를 판단하지 않는다. 적의 추적 반경, 이동 속도, 플레이어와 동시에 보이는지까지 확인한다.
- 방 끝에는 다음 방이나 보스 전으로 정리할 여백을 둔다.
- 전투 강도와 휴식 구간이 번갈아 나타나도록 구성한다.

```powershell
pnpm --filter @soot/client exec vitest run src/game/config/rooms/reachability.test.ts
```

이 테스트는 점프 거리, 지형 도달성, 구덩이와 생성 좌표 오류를 확인한다. 적의 실제 추적, 사선, 화면 내 가시성은 브라우저 플레이 테스트로 별도 확인한다.
