## 4. 협업 방식

게임플레이 기능은 코드와 자동 테스트로 동작을 확인하고, 레벨·오디오 작업은 측정값과 실제 플레이 피드백을 함께 사용했습니다. 구현 과정에서 발견한 문제는 기능 커밋, 버그 수정 커밋, 측정·프롬프트 문서 커밋으로 나누어 기록했습니다.

코덱스 세션은 요구사항을 코드 호출 경로로 구체화하고, `level-design` 관점의 정적 점검과 테스트 실행을 반복하는 개발 보조 역할로 활용했습니다. 5스테이지 비행 진입, 포탈 안내, 적 순찰·피트 경계, 3스테이지 발판 동선 점검이 대표 사례입니다. AI가 판단한 내용을 그대로 확정하지 않고, 팀원이 실제 코드·테스트·플레이 흐름을 확인한 뒤 커밋에 반영했습니다.

AI 도구는 코드 탐색, 레벨 QA, PR 검토, BGM 후보 비교와 테스트 확인에 활용했습니다. AI가 제안한 내용을 팀원이 코드와 실제 플레이로 검증한 뒤 반영했으며, 게임의 기획·구현·최종 판단은 팀원이 담당했습니다.
