# 스테이지 1~4 일반 몬스터 패턴

현재 구현된 일반 몬스터의 전투 규칙을 정리한다. 보스 패턴은 제외한다. 수치는 별도 표기가 없으면 월드 좌표의 px와 ms 기준이다.

## 전체 요약

| 스테이지 | 일반 몬스터 | 핵심 요구 행동 |
| --- | --- | --- |
| 1 // THE CITY | 근접형, 총기형, 비행형 | 기본 거리 조절, 근접 예고 회피, 상하 조준 |
| 2 // THE BACK ALLEYS | 근접형, 총기형, 비행형 | 스테이지 1 패턴을 더 빠른 속도와 구덩이 지형에서 처리 |
| 3 // THE UNDERGROUND | 파이프형, 포획형, 봉쇄형 | 낙하 표식 회피, 구속 해제, 얼굴 약점 조준과 점프 |
| 4 // THE INFERNO | 지옥견, 처형 인형, 심판의 눈 | 돌진선과 낙하 표식 회피, 방사 탄 사이 공간 확보 |

## 공통 규칙

- 일반 몬스터는 방 시작과 함께 생성되고, 모두 처치해야 클리어 포탈이 열린다.
- 지상 몬스터는 바닥, 발판, 피트 가장자리 장벽과 충돌한다. 피트 위로 걸어 나가지 않는다.
- 기본 투사체 피격은 몬스터를 160ms 동안 경직시키고 수평 넉백과 작은 수직 팝업을 준다.
- 기본 피격 연출은 70ms 흰색 플래시다. 몬스터별 무적·방패 판정이 피해를 거부하면 플래시는 발생하지 않는다.
- 스테이지 1·2의 지상형은 자체 사망 애니메이션 뒤 400ms 동안 잔해로 남고, 350ms 동안 페이드아웃한다.
- 스테이지 1·2는 전투 로직과 애니메이션 프레임 구성을 공유한다. 스테이지별 차이는 아틀라스, 방 배치, 지형, 전투 강도다.
- 방의 `intensity`는 스테이지 1·2 기본 몬스터의 이동 속도를 곱하고 총기형·비행형의 사격 간격을 나눈다. 체력, 피해, 감지 거리, 근접 공격 타이밍, 순찰 속도는 바뀌지 않는다.
- 스테이지 3·4 전용 몬스터는 현재 `intensity` 배율을 적용하지 않고 각 전용 설정값을 그대로 사용한다.

## 스테이지 1 // THE CITY

스테이지 1은 세 기본 역할을 한 종류씩 읽게 한 뒤 조합하는 학습 구간이다. 구덩이가 없고, 첫 방은 근접형 두 기를 먼저 보여 준 뒤 총기형과 비행형을 합류시킨다.

### 근접형 (`melee`, `stage-1-neared`)

| 항목 | 값 |
| --- | ---: |
| 체력 | 60 |
| 감지 거리 | 420 |
| 추격 속도 | 190 |
| 비감지 순찰 | 생성점 기준 좌우 90, 속도 70 |
| 공격 시작 거리 | 수평 92 이내, 수직 차이 74 이내 |
| 공격 판정 거리 | 수평 118 |
| 피해 | 15 |

상태 흐름:

```text
순찰 → 감지 → 추격 → 340ms 들어올리기 → 200ms 휘두르기
     → 520ms 회복 → 추격
```

- 들어올리기가 명확한 공격 예고다. 뒤로 이동하거나 점프해 수직 판정을 벗어날 수 있다.
- 휘두르기 한 번에 피해는 최대 1회 적용된다.
- 강한 넉백으로 경직되면 진행 중인 들어올리기·휘두르기가 취소되고 추격 상태로 돌아간다.
- 접촉 자체로는 피해를 주지 않는다. 실제 봉 휘두르기 판정만 피해를 준다.

플레이 대응: 들어올리는 340ms 동안 사거리 밖으로 빠지거나 점프한다. 공격 취소가 가능한 넉백 무기도 유효하다.

### 총기형 (`ranged`, `stage-1-ranged`)

| 항목 | 값 |
| --- | ---: |
| 체력 | 100 |
| 감지 거리 | 520 |
| 재배치 속도 | 135 |
| 선호 사격 거리 | 360 ± 55 |
| 사격 간격 | 900ms |
| 탄속 / 수명 | 430 / 1,800ms |
| 탄환 피해 | 10 |

- 플레이어와 거리가 415보다 멀면 접근한다.
- 거리가 305보다 가까우면 후퇴한다.
- 305~415에서는 정지하고 플레이어를 향해 사격한다.
- 사격 직후 220ms 동안 공격 포즈를 유지한다.
- 감지 밖에서는 근접형과 같은 안전 순찰 구간을 왕복한다.

플레이 대응: 선호 거리에서 사격전을 오래 유지하지 않는다. 빠르게 접근해 후퇴를 강제하거나 발판으로 사선을 끊는다.

### 비행형 (`flying`, `stage-1-flying`)

| 항목 | 값 |
| --- | ---: |
| 체력 | 45 |
| 감지 거리 | 560 |
| 이동 속도 | 150 |
| 사격 간격 | 1,300ms |
| 탄속 / 수명 | 360 / 2,000ms |
| 탄환 피해 | 8 |
| 순찰 궤도 | 생성점 기준 X ±100, Y ±28, 주기 3,200ms |

- 감지 전후 모두 지정된 사인 곡선 순찰을 계속한다.
- 플레이어가 감지 거리 안에 있을 때만 방향을 맞추고 사격한다.
- 피격 경직 중에는 `hit` 포즈로 멈춘 뒤 `idle`로 돌아간다.
- 사망 시 `death-fall`로 바닥까지 낙하하고 `death-land` 뒤 잔해가 사라진다. 낙하 시간은 높이에 따라 120~900ms다.

플레이 대응: 수평 탄만 쏘지 말고 위쪽을 조준한다. 탄속이 총기형보다 느리므로 이동 방향을 바꿔 피한다.

### 방 배치

| 방 | 근접형 | 총기형 | 비행형 | 합계 | 설계 의도 |
| --- | ---: | ---: | ---: | ---: | --- |
| ROOM 01 | 3 | 2 | 1 | 6 | 근접 단독 반복 → 총기형 소개 → 혼합 교전 → 비행형 |
| ROOM 02 | 3 | 2 | 1 | 6 | 기본 교전 압축 → 세 유형 최종 조합 |

## 스테이지 2 // THE BACK ALLEYS

스테이지 2의 세 몬스터는 스테이지 1과 같은 상태·공격 로직을 쓴다. 전용 아틀라스(`stage-2-neared`, `stage-2-ranged`, `stage-2-flying`)로 외형만 바뀌며, 방 강도 때문에 이동과 사격 주기가 빨라진다.

### 강도 적용 결과

| 방 | 강도 | 근접 추격 | 총기 이동 / 사격 | 비행 이동 / 사격 |
| --- | ---: | ---: | ---: | ---: |
| ROOM 01 | 1.15 | 218.5 | 155.25 / 약 783ms | 172.5 / 약 1,130ms |
| ROOM 02 | 1.20 | 228 | 162 / 750ms | 180 / 약 1,083ms |

다음 값은 스테이지 1과 동일하다.

- 근접형: 체력 60, 피해 15, 감지 420, `340ms 예고 → 200ms 공격 → 520ms 회복`
- 총기형: 체력 100, 피해 10, 감지 520, 선호 거리 360 ±55, 탄속 430
- 비행형: 체력 45, 피해 8, 감지 560, 탄속 360, X ±100/Y ±28 순찰

### 지형과 조합 변화

- 처음에는 적과 겹치지 않는 구덩이로 점프를 가르치고, 이후 구덩이 주변 교전에 세 기본 역할을 섞는다.
- 지상형은 피트 가장자리 장벽에서 멈춘다. 플레이어를 따라 구덩이로 추락하지 않는다.
- 발판은 플레이어와 적 탄환을 모두 막는다. 총기형의 사선을 끊는 엄폐이면서, 비행형을 공격하기 위한 높이 경로다.
- 같은 패턴이라도 이동 속도와 사격 빈도가 높아져 우선순위 판단과 이동 중 조준을 더 강하게 요구한다.

### 방 배치

| 방 | 근접형 | 총기형 | 비행형 | 합계 | 설계 의도 |
| --- | ---: | ---: | ---: | ---: | --- |
| ROOM 01 | 3 | 3 | 2 | 8 | 입구·중간·출구의 세 무리, 후반 피트와 혼합 |
| ROOM 02 | 3 | 3 | 3 | 9 | 세 무리 반복, 비행 압박 증가 |

## 스테이지 3 // THE UNDERGROUND

스테이지 3은 앞선 세 기본 역할을 사용하지 않는다. 포획, 매복, 진로 봉쇄를 담당하는 전용 몬스터 세 종류로 교체된다.

### 파이프형 / 천장 정비 안드로이드 (`ceiling-maintainer`, `stage-3-flying`)

| 항목 | 값 |
| --- | ---: |
| 체력 | 70 |
| 감지 거리 | 620 |
| 파이프 이동 속도 | 155 |
| 낙하물 예고 | 650ms |
| 낙하물 이동 시간 | 420ms |
| 낙하물 폭발 반경 / 피해 | 54 / 12 |
| 공격 쿨다운 | 1,450ms |
| 바닥 전환 조건 | 체력 30% 이하, 즉 21 이하 |
| 바닥 돌진 속도 / 피해 | 330 / 14 |

파이프 상태:

```text
crawl → warning → 낙하물 투하 → relocate → crawl
```

- 플레이어의 현재 X를 잠그고 바닥에 폭 108의 표식을 표시한다.
- 650ms 뒤 금속 파편이 420ms 동안 표식으로 낙하한다.
- 폭발 시 플레이어가 표식 반경 54 안이고 화면 하부에 있을 때 피해 12를 준다.
- 공격 뒤에는 현재 파이프의 반대쪽으로 빠르게 이동한다. 이동 중에도 피해를 줄 수 있다.

저체력 바닥 상태:

```text
falling → 착지 → 1,000ms 표식 → ground-dash
        → 목표·벽 도달 → 1,000ms 휴식 → 다시 표식
```

- 낙하 중에는 투사체 피해를 전혀 받지 않는다. 낙하가 끝나면 다시 피해를 받는다.
- 착지 뒤 플레이어 위치를 잠그고 1초 후 해당 X까지 돌진한다. 돌진 중에만 접촉 피해 14를 준다.
- 같은 돌진 접촉 피해는 700ms 쿨다운을 가진다.
- 2층 발판은 통과해 1층까지 떨어진다. 1층 바닥과 피트 가장자리 장벽에는 충돌하므로 구덩이 위로 돌진하지 않는다.

플레이 대응: 파이프 단계에서는 바닥 표식을 보고 이동한다. 체력을 30% 이하로 내린 뒤 낙하 중에는 회피에 집중하고, 착지 후 1초 표식이 고정되면 위치를 바꾼다.

### 포획형 / 생존자 포획 안드로이드 (`captor`, `stage-3-ranged`)

| 항목 | 값 |
| --- | ---: |
| 체력 | 90 |
| 감지 거리 | 610 |
| 접근 속도 / 접근 기준 | 75 / 거리 430 초과 |
| 케이블 예고 | 620ms |
| 케이블 회수 시간 | 1,000ms |
| 회피 판정 | 잠근 위치에서 70 초과 이동 |
| 케이블 절단 누적 피해 | 25 |
| 근접 충격 진입 거리 | 92 |
| 전기 포박 | 2,000ms, 350ms마다 피해 6 |
| 공격 쿨다운 | 1,900ms |

상태 흐름:

```text
ready → warning → tethered → shocking → recover → ready
                    └ 대시·누적 피해 25 → recover
```

- 예고 시작 시 플레이어 위치를 잠그고 케이블과 바닥 경로를 표시한다.
- 620ms 뒤 잠근 위치에서 70보다 멀리 이동했으면 공격이 빗나간다.
- 맞으면 플레이어 입력 속도 계수를 0으로 만들고, 남은 1초 안에 포획기까지 도달하도록 당김 속도를 계산한다. 최소 당김 속도는 240이다.
- 거리 92 이내로 끌려오면 최대 2초 동안 붙잡고 즉시 시작해 350ms마다 피해 6을 준다.
- 대시하면 `tethered`와 `shocking` 어느 상태에서든 즉시 케이블이 해제된다.
- 구속 중 포획형에게 누적 피해 25를 주어도 케이블이 끊어진다.
- 해제 뒤 480ms 회복을 거치며, 다음 공격은 해제 시점부터 1,900ms 뒤 가능하다.
- 별도 접촉 피해는 없다.

플레이 대응: 620ms 경고선에서 점프나 대시로 70 이상 벗어난다. 잡혔다면 대시 또는 집중 사격 25 피해로 즉시 끊는다. 다른 적과 함께 있을 때 최우선 처치 대상이다.

### 봉쇄형 / 이동식 봉쇄 안드로이드 (`blocker`)

| 항목 | 값 |
| --- | ---: |
| 체력 | 150 |
| 감지 거리 | 520 |
| 전진 속도 | 68 |
| 내려찍기 시작 거리 | 190 |
| 내려찍기 예고 | 560ms |
| 회복 | 760ms |
| 공격 쿨다운 | 1,500ms |
| 충격파 거리 / 피해 | 210 / 14 |
| 몸체 / 얼굴 약점 | 80×120 / 80×18 |
| 얼굴 판정 여유 | 탄환 중심 기준 8 |

상태 흐름:

```text
advance → windup → 충격파 → recover → advance
```

- 감지되면 방패를 앞세우고 플레이어 방향으로 천천히 전진한다.
- 거리 190 이내에서 멈추고 얼굴 마커를 90ms 간격으로 점멸하며 560ms 동안 내려찍기를 예고한다.
- 내려찍기는 좌우 210 이내의 바닥 근처 플레이어에게 피해 14를 준다. 점프해 바닥 판정을 벗어나면 피할 수 있다.
- 내려찍기 뒤 760ms 동안 정지한다.
- 몸 상단의 얼굴 영역 `80×18`만 투사체 피해를 받는다. 이는 전체 몸체 면적의 15%이며, 실제 탄환 판정에는 가장자리 8px 여유가 있다.
- 얼굴 밖에 맞은 탄환은 피해가 완전히 0이 되며 방패 스파크만 표시된다. 탄환 반사는 없다.
- 얼굴 약점은 전진·예고·회복 상태 모두 열려 있다. 내려찍기 뒤 별도 피해 배율은 없다.
- 별도 접촉 피해는 없다.
- 현재 전용 스프라이트가 없어 `blocker-placeholder` 텍스처를 사용한다.

플레이 대응: 녹색 얼굴 마커를 정밀 조준한다. 충격파 예고에는 점프하고, 760ms 회복 시간에 얼굴을 집중 공격한다.

### 방 배치

| 방 | 봉쇄형 | 포획형 | 파이프형 | 합계 | 지형 |
| --- | ---: | ---: | ---: | ---: | --- |
| ROOM 01 | 2 | 2 | 2 | 6 | 파이프 2개, 피트 4개 |
| ROOM 02 | 2 | 2 | 3 | 7 | 파이프 3개, 피트 4개 |

세 역할은 서로 다른 대응을 동시에 요구한다.

| 역할 | 공간 압박 | 우선 대응 |
| --- | --- | --- |
| 파이프형 | 상단과 낙하 지점, 저체력 돌진선 | 표식에서 이탈하고 돌진 직전 위치 변경 |
| 포획형 | 플레이어 이동 자체 제한 | 경고선 회피, 대시·집중 사격으로 케이블 절단 |
| 봉쇄형 | 느린 전진과 지상 충격파로 전투 공간 축소 | 얼굴 조준, 충격파 점프, 회복 시간 집중 공격 |

## 스테이지 4 // THE INFERNO

스테이지 4는 악마 환각으로 보이는 전용 몬스터 세 종류를 사용한다. 세 종류는 공격 예고부터 회복까지 공용 공격 슬롯을 점유하며, 한 방에서 동시에 공격하는 몬스터는 최대 두 기로 제한된다.

- 피격 시 일반 흰색 플래시 대신 65ms 동안 청록색 안드로이드 실루엣이 드러난다.
- 사망 시 악마 형상이 사라지고 기계 부품 잔해가 흩어지는 연출을 사용한다.
- 세 종류 모두 현재 전용 아틀라스 없이 플레이스홀더 텍스처를 사용한다.

### 지옥견 (`infernal-hound`)

| 항목 | 값 |
| --- | ---: |
| 체력 | 85 |
| 감지 거리 | 680 |
| 추적 속도 | 150 |
| 돌진 예고 | 650ms |
| 돌진 속도 / 최대 시간 | 820 / 1,000ms |
| 돌진 피해 | 20 |
| 기절 / 공격 쿨다운 | 700ms / 1,450ms |
| 마그마 흔적 생성 간격 / 유지 시간 | 90ms / 1,000ms |
| 마그마 피해 | 400ms마다 4 |

상태 흐름:

```text
ready → warning → charging → stunned → ready
```

- 감지 범위 안에서는 플레이어를 속도 150으로 추적한다.
- 공격을 시작하면 플레이어가 있던 방향을 잠그고 월드 끝까지 이어지는 붉은 돌진선을 650ms 동안 표시한다.
- 예고가 끝나면 잠근 방향으로 최대 1초 동안 돌진하며, 벽에 부딪히면 즉시 멈춘다.
- 한 번의 돌진은 플레이어에게 최대 한 번만 피해 20을 준다.
- 돌진 중 90ms마다 폭 54의 마그마 흔적을 남긴다. 흔적은 1초 동안 유지되며 바닥에 닿아 있는 플레이어에게 400ms마다 피해 4를 준다.
- 돌진이 끝나면 700ms 동안 기절하고, 기절 종료 시점부터 1,450ms 뒤 다음 공격이 가능하다.

플레이 대응: 650ms 동안 표시되는 돌진선을 보고 수직 이동하거나 점프한다. 돌진 뒤 700ms 기절 시간에 집중 공격하고, 지나간 자리에 남은 마그마 위에 착지하지 않는다.

### 처형 인형 (`executioner-doll`)

| 항목 | 값 |
| --- | ---: |
| 체력 | 100 |
| 감지 거리 | 700 |
| 공중 이동 속도 | 230 |
| 플레이어 위 유지 높이 | 190 |
| 내려찍기 시작 조건 | 수평 거리 90 이내 |
| 내려찍기 예고 | 700ms |
| 내려찍기 속도 | 1,000 |
| 착지 회복 / 공격 쿨다운 | 700ms / 1,700ms |
| 충격파 거리 / 피해 | 180 / 16 |

상태 흐름:

```text
hover → warning → slamming → landed → rising → hover
```

- 평상시 플레이어보다 190 위를 유지하며 수평 위치를 따라간다.
- 플레이어와 수평 거리 90 이내에서 공격 슬롯을 얻으면 현재 X를 잠그고 바닥에 폭 104의 표식을 700ms 동안 표시한다.
- 예고 중에는 잠근 X의 상공으로 이동한 뒤 속도 1,000으로 수직 낙하한다.
- 착지 시 같은 높이에서 좌우 180 이내에 있는 플레이어에게 충격파 피해 16을 준다.
- 착지 뒤 700ms 동안 멈춘 다음 다시 플레이어 위로 상승한다. 별도 접촉 피해는 없다.

플레이 대응: 표식이 고정된 뒤 좌우로 이탈한다. 충격파는 착지 지점에서 180보다 멀리 떨어지거나 다른 높이의 발판으로 이동해 피한다.

### 심판의 눈 (`judgment-eye`)

| 항목 | 값 |
| --- | ---: |
| 체력 | 75 |
| 감지 거리 | 720 |
| 이동 속도 | 150 |
| 추적 조준 | 600ms |
| 구체 충전 / 유지 시간 | 300ms / 1,000ms |
| 방사 탄환 수 | 6발과 8발 교대 |
| 탄속 / 수명 / 피해 | 220 / 1,800ms / 8 |
| 재배치 / 공격 쿨다운 | 800ms / 2,100ms |

상태 흐름:

```text
ready → tracking → orb → repositioning → ready
```

- 평상시 플레이어 좌우 약 300, 위쪽 180 지점을 따라다닌다.
- 공격을 시작하면 600ms 동안 플레이어의 현재 위치를 계속 추적해 조준점을 갱신한다.
- 추적이 끝난 위치에 구체를 만들고 300ms 뒤 방사형 탄환을 발사한다. 공격할 때마다 6발과 8발을 번갈아 사용한다.
- 탄환은 속도 220으로 이동하며 플레이어에게 피해 8을 준다. 1,800ms가 지나거나 월드 밖으로 나가면 사라진다.
- 구체 공격이 끝나면 플레이어에게서 수평으로 약 320 떨어진 지점과 교대로 바뀌는 높이로 최대 800ms 동안 재배치한다.

플레이 대응: 600ms 추적이 끝나기 직전 조준점을 전투 공간 가장자리로 유도한다. 구체가 생성되면 가까이 머물지 말고 방사 탄 사이의 간격이 벌어지는 방향으로 이동한다.

### 방 배치

| 방 | 지옥견 | 처형 인형 | 심판의 눈 | 합계 | 지형 |
| --- | ---: | ---: | ---: | ---: | --- |
| ROOM 01 | 4 | 2 | 2 | 8 | 고립된 낮은 엄폐 발판 4개, 중간 발판 2개, 피트 4개 |
| ROOM 02 | 4 | 2 | 2 | 8 | 세 높이의 수직 발판군, 피트 4개 |

세 역할은 최대 두 개의 공격만 겹치면서 서로 다른 회피 축을 요구한다.

| 역할 | 공간 압박 | 우선 대응 |
| --- | --- | --- |
| 지옥견 | 바닥 전체 돌진선과 남는 마그마 | 수직 회피, 기절 중 공격, 흔적 위 착지 방지 |
| 처형 인형 | 플레이어 위치를 잠그는 수직 낙하와 지상 충격파 | 표식 이탈, 착지 높이 변경 |
| 심판의 눈 | 이동을 추적하는 조준점과 방사형 탄막 | 가장자리로 유도, 탄 사이 간격 확보 |
