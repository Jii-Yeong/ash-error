## 게임 소개

`ASH//ERROR`는 이동, 점프, 대시와 정밀 조준을 결합한 웹 기반 2D 액션 슈팅 플랫폼 게임입니다.

플레이어는 깨끗하지만 텅 빈 미래 도시에서 출발해 뒤틀린 뒷골목과 생존자의 흔적이 남은 지하 시설을 지나갑니다. 도시의 기억이 악마적인 형태로 변한 지옥을 돌파한 뒤에는, 잔혹한 제거를 정화와 구원으로 포장한 인공 낙원 `THE RETURN`이 기다립니다.

각 방은 입장과 함께 봉쇄됩니다. 서로 다른 역할을 가진 안드로이드들을 모두 처치하면 다음 포탈이 열리고, 스테이지 마지막에는 고유한 공격 순환과 페이즈 전환을 가진 보스가 등장합니다. 전투는 단순한 화력 경쟁보다 공격 예고를 읽고, 안전 구간을 찾고, 적의 약점을 공략하는 데 초점을 맞췄습니다.

## 주요 특징

- **다섯 개의 스테이지**: 도시, 뒷골목, 지하, 지옥, 인공 낙원으로 이어지는 시각·음악·전투 변화
- **지상전에서 공중전으로의 전환**: 점프와 발판 중심의 전투가 마지막 스테이지에서 자유 비행과 탄막 회피로 확장
- **역할이 분명한 적 구성**: 근접 압박, 원거리 견제, 비행 사격, 포획, 진로 봉쇄, 돌진과 방사 탄막을 조합
- **패턴 중심의 보스전**: 공격 예고, 체력 임계점, 무적 구간, 약점 노출과 페이즈 전환으로 구성된 5종 보스
- **네 종류의 무기**: 연사, 산탄, 점사, 관통에 특화된 무기를 획득하고 최대 4개 슬롯에서 전환
- **전투 피드백**: 무기별 반동, 총구 화염, 탄환 형태, 타격 정지, 화면 흔들림과 전용 효과음
- **픽셀 아트 연출**: 스테이지마다 달라지는 플레이어·적·보스 스프라이트와 산업형 SF 인터페이스

## 스테이지

| 스테이지 | 공간 | 전투 변화 |
| --- | --- | --- |
| 1 // `THE CITY` | 깨끗하고 텅 빈 미래 도시 | 이동, 조준, 근접 예고와 비행 적 대응 학습 |
| 2 // `THE BACK ALLEYS` | 낮은 채도의 네온 뒷골목 | 빨라진 적과 구덩이·발판을 이용한 엄폐 전투 |
| 3 // `THE UNDERGROUND` | 배관과 습기로 뒤덮인 지하 시설 | 낙하 표식, 케이블 포획, 얼굴 약점과 충격파 대응 |
| 4 // `HELL` | 도시의 기억이 뒤틀린 용암 지대 | 돌진선, 연속 지면 분출과 마그마 장판 회피 |
| 5 // `THE RETURN` | 정화와 구원을 가장한 인공 낙원 | 자유 비행, 회전하는 안전 구간, 부채꼴·방사 탄막과 최종 보스 |

## 무기

| 무기 | 특징 |
| --- | --- |
| `SMG` | 빠른 연사와 안정적인 지속 피해 |
| `SHOTGUN` | 근거리 5발 산탄과 강한 넉백 |
| `BURST RIFLE` | 빠른 3점사와 중거리 집중 사격 |
| `RAIL RIFLE` | 높은 단발 피해와 관통 공격 |

무기마다 발사 속도, 투사체 속도, 산탄도, 관통력과 반동이 다릅니다. 보스 장갑은 무기 특성에 따라 피해를 다르게 받아, 강한 단발 무기 하나가 모든 패턴을 건너뛰지 않도록 전투 시간을 조정했습니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| `A` / `D`, `←` / `→` | 좌우 이동 |
| `W` / `↑` / `SPACE` | 점프·비행 상승 |
| `W` / `↑` (열린 포탈 앞) | 다음 방 진입 |
| `S` / `↓` | 빠른 낙하·비행 하강 |
| `SHIFT` / 마우스 오른쪽 버튼 | 대시 |
| 마우스 이동 | 조준 |
| 마우스 왼쪽 버튼 | 발사 |
| `E` | 근처 무기 장착 |
| `1`–`4` | 무기 슬롯 전환 |
| `ESC` | 일시정지·가이드 닫기 |
| `R` / `ENTER` | 사망·클리어 후 재시작 |

## 실행 방법

### 요구 환경

- Node.js `22.x` (`22.12.0` 이상, `23` 미만)
- pnpm `10.34.5`

### 설치 및 개발 서버

```bash
pnpm install
pnpm dev
```

터미널에 표시되는 Vite 개발 서버 주소를 브라우저에서 열고, 타이틀 화면에서 `ENTER`를 누르면 시작합니다.

### 빌드와 검증

```bash
pnpm build
pnpm lint
pnpm test
pnpm test:e2e
```

## 기술 구성

| 영역 | 기술 |
| --- | --- |
| 게임 런타임 | Phaser 4 |
| 인터페이스 | React 19 |
| 상태 관리 | Zustand |
| 언어 | TypeScript |
| 개발·빌드 | Vite, pnpm workspace |
| 단위 테스트 | Vitest |
| E2E 테스트 | Playwright |
| 배포 | Vercel |

React는 HUD, 설정, 일시정지와 개발용 관리 UI를 담당하고 Phaser는 월드, 물리, 전투와 연출을 담당합니다. 두 영역은 이벤트와 공유 상태를 통해 연결됩니다.

## 저장소 구조

```text
soot/
├── client/                 # React + Phaser 게임 클라이언트
│   ├── public/assets/      # 픽셀 아트, 배경, UI, 오디오
│   ├── src/app/            # HUD와 React 인터페이스
│   └── src/game/           # 씬, 전투, 엔티티, 스테이지 설정
├── docs/                   # 전투 패턴, 레벨 디자인, 오디오 문서
├── server/                 # 향후 서버 런타임을 위한 workspace
├── tools/                  # 오디오 생성·측정·루프 가공 도구
└── spritecook-assets.json  # 생성 스프라이트 출처와 해시 기록
```
